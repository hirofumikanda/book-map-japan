## Purpose

MapLibre GL JS v6を用いてOpenStreetMap Standard背景地図上に日本全国の書店POIを表示し、チェーン店の優先表示・チェーン別アイコンによる視覚的識別・絞り込み・プロパティのポップアップ確認を可能にするWebマップフロントエンド。

## ADDED Requirements

### Requirement: 背景地図の表示
システムはMapLibre GL JS v6を用いて、透過度0.50のOpenStreetMap Standard背景地図を表示しなければならない(SHALL)。

#### Scenario: 初期表示で背景地図が読み込まれる
- **WHEN** ユーザーがマップページを開く
- **THEN** OpenStreetMap Standardの背景タイルが表示された状態でマップが初期化される

#### Scenario: 背景地図が半透明で表示される
- **WHEN** ユーザーがマップページを開く
- **THEN** OpenStreetMap Standardの背景タイルは透過度0.50(不透明度50%)で表示される

### Requirement: 書店POIのシンボルレイヤ表示
システムは配信されているPMTilesをソースとして読み込み、書店POIをシンボルレイヤとして地図上に表示しなければならない(SHALL)。PMTilesの生成ズーム範囲(z10-14)を外れるズームレベルでは、オーバーズームまたは非表示によって適切に扱わなければならない(SHALL)。

ブランド識別情報(`brand`・`operator`・`name`等)が既知チェーンに一致するPOI(チェーン店)はズームレベル10以上で表示しなければならない(SHALL)。どの既知チェーンにも一致しないPOI(チェーン店以外)はズームレベル14以上でのみ表示しなければならず(SHALL)、ズームレベル14未満では表示してはならない(SHALL NOT)。この出し分けはチェーン絞り込みプルダウンメニューが「すべて」を選択している場合に適用する。

#### Scenario: ズーム範囲内でチェーン店POIシンボルが表示される
- **WHEN** ユーザーが地図をズームレベル10から14の範囲内で表示し、プルダウンメニューが「すべて」である
- **THEN** 表示範囲内の既知チェーンに一致する書店POIがシンボルとして描画される

#### Scenario: ズームレベル14未満ではチェーン店以外のPOIが表示されない
- **WHEN** ユーザーが地図をズームレベル10以上14未満で表示し、プルダウンメニューが「すべて」である
- **THEN** どの既知チェーンにも一致しない書店POIのシンボルは表示されない

#### Scenario: ズームレベル14以上ではチェーン店以外のPOIも表示される
- **WHEN** ユーザーが地図をズームレベル14以上で表示し、プルダウンメニューが「すべて」である
- **THEN** どの既知チェーンにも一致しない書店POIのシンボルも(confidenceしきい値を満たす範囲で)表示される

#### Scenario: 最大ズームを超えてもPOIが表示され続ける
- **WHEN** ユーザーが地図をズームレベル14を超えて拡大する
- **THEN** z14タイルのオーバーズーム表示によりPOIシンボルが表示され続ける

#### Scenario: 最小ズーム未満ではPOIが表示されない
- **WHEN** ユーザーが地図をズームレベル10未満に縮小する
- **THEN** 書店POIのシンボルレイヤは表示されない

### Requirement: チェーン店のアイコンによる視覚的識別
システムはPOIのブランド識別情報(`brand`・`operator`・`name`等)に基づき、既知のチェーンに該当するPOIを、`web/public/img/`配下の当該チェーンに割り当てられた画像アイコンで表示しなければならない(SHALL)。どの既知チェーンにも該当しないPOIは汎用アイコン`book.png`で表示しなければならない(SHALL)。

既知チェーンとアイコン画像の対応は次のとおりでなければならない(SHALL)。

| チェーン | アイコン画像 |
| --- | --- |
| くまざわ書店 | `kumazawa.png` |
| 未来屋書店 | `miraiya.png` |
| 宮脇書店 | `miyawaki.png` |
| 紀伊國屋書店 | `kinokuniya.png` |
| 丸善 | `maruzen.png` |
| ジュンク堂書店 | `junku.png` |
| 文教堂 | `bunkyo.png` |
| 三省堂書店 | `sansei.png` |
| 有隣堂 | `yurin.png` |
| その他(未一致) | `book.png` |

チェーン判定は、ブランド識別情報を`brand`・`operator`・`name`の順に探索し、既知チェーン名との部分一致で行わなければならない(SHALL)。法人格表記(株式会社等)・全角/半角・前後の空白といった表記ゆれによって判定が失敗してはならない(SHALL NOT)。

#### Scenario: 既知チェーンのPOIが専用アイコンで表示される
- **WHEN** ブランド識別情報が既知チェーン(例: 紀伊國屋書店)に一致するPOIを表示する
- **THEN** そのPOIは当該チェーンに割り当てられたアイコン(`kinokuniya.png`)で描画される

#### Scenario: 未分類のPOIが汎用アイコンで表示される
- **WHEN** ブランド識別情報がどの既知チェーンにも一致しないPOIを表示する
- **THEN** そのPOIは汎用の書店アイコン(`book.png`)で描画される

#### Scenario: 法人格表記を含むブランド名でもチェーンとして判定される
- **WHEN** ブランド識別情報が法人格表記を含む文字列(例: 株式会社有隣堂)であるPOIを表示する
- **THEN** そのPOIは有隣堂のアイコン(`yurin.png`)で描画される

#### Scenario: 店名にチェーン名を含むPOIがチェーンとして判定される
- **WHEN** `brand`を持たないが`name`に既知チェーン名を含むPOI(例: くまざわ書店○○店)を表示する
- **THEN** そのPOIは当該チェーンのアイコン(`kumazawa.png`)で描画される

### Requirement: チェーン店の絞り込みプルダウンメニュー
システムは地図の左上に、表示するチェーン店を絞り込むプルダウンメニュー(選択式コントロール)を表示しなければならない(SHALL)。選択肢は「すべて」と、既知チェーン各1件で構成しなければならない(SHALL)。ページ初期表示時の選択値は「すべて」でなければならない(SHALL)。

「すべて」が選択されている場合、システムは「書店POIのシンボルレイヤ表示」要件のズーム出し分け(チェーン店はz10以上、チェーン店以外はz14以上)に従って全POIを表示しなければならない(SHALL)。

特定のチェーンが選択されている場合、システムは当該チェーンのブランド識別情報に一致するPOIのみを表示し(SHALL)、他のチェーンおよびチェーン店以外のPOIを表示してはならない(SHALL NOT)。この場合、当該チェーンのPOIはズームレベル10以上で表示しなければならない(SHALL)。

いずれの選択状態でも、ズームレベルに応じたconfidenceしきい値フィルタは引き続き適用しなければならない(SHALL)。

プルダウンメニューはマウス操作(PC)およびタッチ操作(スマートフォン)のいずれでも操作可能でなければならず(SHALL)、地図コントロールと調和した外観を持たなければならない(SHALL)。プルダウンメニュー上の操作が地図のパン・ズーム操作を誤って発生させてはならない(SHALL NOT)。

#### Scenario: 初期表示で左上にプルダウンメニューが「すべて」で表示される
- **WHEN** ユーザーがマップページを開く
- **THEN** 地図の左上にチェーン絞り込みプルダウンメニューが表示され、選択値は「すべて」である

#### Scenario: プルダウンメニューに全チェーンと「すべて」が選択肢として並ぶ
- **WHEN** ユーザーがプルダウンメニューを開く
- **THEN** 「すべて」と既知チェーン9件が選択肢として表示される

#### Scenario: 特定チェーンを選択すると当該チェーンのPOIのみ表示される
- **WHEN** ユーザーがプルダウンメニューで特定のチェーン(例: ジュンク堂書店)を選択する
- **THEN** 当該チェーンのブランド識別情報に一致するPOIのみが表示され、他チェーンおよびチェーン店以外のPOIは表示されない

#### Scenario: 特定チェーン選択時はz14未満でも当該チェーンのPOIが表示される
- **WHEN** ユーザーが特定のチェーンを選択し、地図をズームレベル10以上14未満で表示する
- **THEN** 当該チェーンのPOIが(confidenceしきい値を満たす範囲で)表示される

#### Scenario: 「すべて」に戻すと全POIの表示条件に戻る
- **WHEN** ユーザーがプルダウンメニューを特定チェーンから「すべて」に戻す
- **THEN** チェーン店はz10以上、チェーン店以外はz14以上という表示条件で全POIが表示される

#### Scenario: 絞り込み選択後もconfidenceフィルタが維持される
- **WHEN** ユーザーが特定のチェーンを選択して地図をズームレベル15で表示する
- **THEN** 当該チェーンのPOIのうちconfidenceが0.97未満のものは表示されない

### Requirement: ズームレベルに応じたconfidenceフィルタ
システムは書店POIのシンボルレイヤに、現在のズームレベルに応じた`confidence`しきい値以上のPOIのみを表示するフィルタを適用しなければならない(SHALL)。しきい値はズームレベル10以上14以下では0.99以上、15では0.97以上、16では0.95以上、17以上では0.90以上とする。

#### Scenario: z10-14ではconfidence0.99以上のPOIのみ表示される
- **WHEN** ユーザーが地図をズームレベル10から14の範囲内で表示する
- **THEN** confidenceが0.99未満のPOIシンボルは表示されない

#### Scenario: z15ではconfidence0.97以上のPOIのみ表示される
- **WHEN** ユーザーが地図をズームレベル15で表示する
- **THEN** confidenceが0.97未満のPOIシンボルは表示されない

#### Scenario: z16ではconfidence0.95以上のPOIのみ表示される
- **WHEN** ユーザーが地図をズームレベル16で表示する
- **THEN** confidenceが0.95未満のPOIシンボルは表示されない

#### Scenario: z17以上ではconfidence0.90以上のPOIが表示される
- **WHEN** ユーザーが地図をズームレベル17以上で表示する
- **THEN** confidenceが0.90以上のPOIシンボルはすべて表示される

### Requirement: POIラベルの配置
システムは書店POIのシンボルに、店名等のラベルをテキストとして表示しなければならない(SHALL)。ラベルはズームレベル15以上でのみ表示しなければならず(SHALL)、ズームレベル15未満では表示してはならない(SHALL NOT)。ズームレベル15未満ではPOIアイコンのみを表示する。ラベルはアイコンの左への配置を優先し、左側に配置すると他のラベルと衝突する場合はアイコンの上に配置しなければならない(SHALL)。ラベルが配置できない場合でもアイコンは表示され続けなければならない(SHALL)。ラベルの表示にはグリフフォントソース`https://demotiles.maplibre.org/font/{fontstack}/{range}.pbf`のNoto Sans Regularを使用しなければならない(SHALL)。

#### Scenario: ズームレベル15未満ではラベルが表示されない
- **WHEN** ユーザーが地図をズームレベル15未満で表示する
- **THEN** 書店POIのアイコンは表示されるが、店名等のラベルは表示されない

#### Scenario: ズームレベル15以上でラベルが表示される
- **WHEN** ユーザーが地図をズームレベル15以上で表示する
- **THEN** 表示中の書店POIシンボルに店名等のラベルが表示される

#### Scenario: POIシンボルの左にラベルが表示される
- **WHEN** ズームレベル15以上で、周囲の他のPOIラベルと衝突しない状態で書店POIシンボルを表示する
- **THEN** 当該POIのアイコンの左にラベルが表示される

#### Scenario: ラベルが衝突する場合はアイコンの上に表示される
- **WHEN** ズームレベル15以上で、アイコンの左にラベルを配置すると他のPOIのラベルと衝突する
- **THEN** 当該POIのラベルはアイコンの上に配置される

#### Scenario: 店名が無いPOIではブランド名がラベルとして表示される
- **WHEN** ズームレベル15以上で、店名を持たないがブランド名を持つPOIを表示する
- **THEN** 当該POIのアイコンのラベルにはブランド名が表示される

### Requirement: POIクリック時のポップアップ表示
システムはユーザーが書店POIのシンボルをクリックした際、そのPOIが保持する各種プロパティ(店名・ブランド・住所・confidence・websites等)をポップアップとして表示しなければならない(SHALL)。`confidence`は表示する場合、丸めや変換を行わず、元の数値をそのまま表示しなければならない(SHALL)。`websites`は表示する場合、各URLをクリック可能なリンクとして表示しなければならない(SHALL)。POIのプロパティはHTMLへ埋め込む際にエスケープしなければならず(SHALL)、`http`/`https`以外のスキームのURLをリンクとして表示してはならない(SHALL NOT)。

#### Scenario: POIシンボルをクリックするとポップアップが表示される
- **WHEN** ユーザーが地図上の書店POIシンボルをクリックする
- **THEN** クリックしたPOIのプロパティ(店名を含む)を表示するポップアップが地図上に表示される

#### Scenario: 何もない場所をクリックしてもポップアップは表示されない
- **WHEN** ユーザーがPOIシンボルが存在しない地図上の地点をクリックする
- **THEN** ポップアップは表示されない

#### Scenario: ポップアップにconfidenceが元の数値のまま表示される
- **WHEN** ユーザーが`confidence`を保持するPOIシンボルをクリックする
- **THEN** ポップアップに当該POIのconfidenceが丸めや変換をされていない元の数値として表示される

#### Scenario: ポップアップにwebsitesがリンクとして表示される
- **WHEN** ユーザーが`websites`を保持するPOIシンボルをクリックする
- **THEN** ポップアップに当該POIのwebsitesの各URLがクリック可能なリンクとして表示される

#### Scenario: websitesを持たないPOIではリンクが表示されない
- **WHEN** ユーザーが`websites`を保持しないPOIシンボルをクリックする
- **THEN** ポップアップにwebsitesのリンクは表示されない

#### Scenario: http/https以外のURLはリンク化されない
- **WHEN** ユーザーが`http`/`https`以外のスキームのURLを`websites`に保持するPOIシンボルをクリックする
- **THEN** 当該URLはクリック可能なリンクとして表示されない

### Requirement: ナビゲーションコントロールの表示
システムは地図右上にMapLibreのナビゲーションコントロール(ズームイン・ズームアウト・コンパス操作を含む)を表示しなければならない(SHALL)。

#### Scenario: 初期表示でナビゲーションコントロールが地図右上に表示される
- **WHEN** ユーザーがマップページを開く
- **THEN** 地図右上にズームイン・ズームアウト・コンパス操作ボタンを含むナビゲーションコントロールが表示される

#### Scenario: ナビゲーションコントロールのズームボタン操作で地図がズームする
- **WHEN** ユーザーがナビゲーションコントロールのズームインボタンをクリックする
- **THEN** 地図のズームレベルが1段階拡大される

### Requirement: 現在地表示コントロールの表示
システムは地図の右下に、ユーザーの現在地を取得して地図上に表示するGeolocateコントロール(ボタン)を表示しなければならない(SHALL)。当該コントロールは同じ右下の帰属表示(attribution)ボタンよりも上に配置しなければならない(SHALL)。

ユーザーがGeolocateコントロールを操作した場合、システムはブラウザのGeolocation APIを用いて現在地の取得を試み、取得に成功した場合は地図を現在地へ移動し、現在地を示すマーカーを地図上に表示しなければならない(SHALL)。現在地の取得に失敗した場合(ユーザーが許可しなかった場合を含む)、システムは地図表示を破壊してはならず(SHALL NOT)、他のコントロール・POI表示は通常どおり動作し続けなければならない(SHALL)。

#### Scenario: 初期表示で右下にGeolocateコントロールが表示される
- **WHEN** ユーザーがマップページを開く
- **THEN** 地図の右下にGeolocateコントロール(現在地ボタン)が表示される

#### Scenario: Geolocateコントロールが帰属表示ボタンより上に配置される
- **WHEN** ユーザーがマップページを開く
- **THEN** 右下のGeolocateコントロールは、同じ右下に表示される帰属表示ボタンよりも上に配置される

#### Scenario: 現在地の取得に成功すると地図が現在地へ移動しマーカーが表示される
- **WHEN** ユーザーがGeolocateコントロールを操作し、ブラウザが現在地の取得を許可して座標を返す
- **THEN** 地図が現在地を中心に移動し、現在地を示すマーカーが地図上に表示される

#### Scenario: 現在地の取得に失敗しても地図は動作し続ける
- **WHEN** ユーザーがGeolocateコントロールを操作し、位置情報へのアクセスが拒否される、または現在地を取得できない
- **THEN** 地図・他のコントロール・書店POIの表示は通常どおり動作し続ける

### Requirement: 地図の初期表示位置
システムはURLハッシュに地図状態(中心座標・ズーム等)が含まれない場合、地図をズームレベル10、皇居(東京都千代田区)周辺を中心として初期化しなければならない(SHALL)。

#### Scenario: ハッシュ無しでページを開くと皇居周辺がズームレベル10で表示される
- **WHEN** ユーザーが地図状態を含まないURL(ハッシュ無し)でマップページを開く
- **THEN** 地図はズームレベル10、皇居周辺を中心として初期化される

### Requirement: 地図状態のURLハッシュ同期
システムは地図の中心座標・ズームレベル・回転・傾きをURLのハッシュ部分に反映し、ハッシュ部分に地図状態を含むURLで開かれた際にはその状態から地図を初期化しなければならない(SHALL)。

#### Scenario: 地図を操作するとURLハッシュが更新される
- **WHEN** ユーザーが地図をパンまたはズームする
- **THEN** ブラウザのURLハッシュが操作後の地図の中心座標・ズーム・回転・傾きを反映して更新される

#### Scenario: ハッシュ付きURLを開くと指定位置で地図が初期化される
- **WHEN** ユーザーが中心座標・ズームを指定したハッシュ付きURLでマップページを開く
- **THEN** 地図はそのハッシュが示す中心座標・ズームで初期化される

### Requirement: 出典への帰属表示
システムは地図上に、背景地図の出典であるOpenStreetMapおよび書店POIデータの出典であるOverture Maps Foundationへの帰属表示(attribution)を含めなければならない(SHALL)。

#### Scenario: 初期表示でOpenStreetMapとOverture Mapsの帰属表示が含まれる
- **WHEN** ユーザーがマップページを開く
- **THEN** 地図の帰属表示にOpenStreetMapおよびOverture Maps Foundationへのクレジットが含まれる

### Requirement: サブパス配信への対応
システムは、オリジン直下ではないサブパス(例: `https://<user>.github.io/<repo>/`)配下から配信された場合でも、PMTiles・アイコン画像・スクリプト等のフロントエンド資産を正しく解決し、地図を表示できなければならない(SHALL)。

#### Scenario: サブパス配下でPOIとアイコンが表示される
- **WHEN** ユーザーがサブパス配下のURLでマップページを開く
- **THEN** PMTilesとアイコン画像が正しく読み込まれ、書店POIがアイコン付きで表示される
